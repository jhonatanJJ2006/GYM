# Hierro

Bitácora personal de clases, gym y comidas, de octubre 2026 a febrero 2027. Pensada para el celular: calendario con filtros, clases semana a semana, ciclo de entreno y comidas. Las fotos de platos y ejercicios vienen de Wikimedia Commons; el autor y la licencia están en cada imagen y en CREDITS.md.

## Comandos

```bash
npm install
npm run dev
npm run build
```

## Vercel

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
