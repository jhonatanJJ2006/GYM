# Hierro

Bitácora personal de clases, gym y comidas, de octubre 2026 a febrero 2027. Pensada para el celular: calendario, semana tipo, ciclo de entreno y comidas.

## Comandos

```bash
npm install
npm run dev
npm run build
```

## Vercel

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
